# Ventures

Two complete businesses, each chosen independently, researched, built and costed.

| Venture | One line | What is working |
| --- | --- | --- |
| [**Plimsoll**](./plimsoll/) | The load line for agent-written code — what share of your merged code an agent wrote, and whether it fails more often | `plimsoll` CLI (18 tests), 24-month model (11 tests) |
| [**Understudy**](./understudy/) | Main street businesses that cannot run without their owner cannot be sold — Understudy makes them transferable | `appraise` engine (43 tests), 24-month model (13 tests) |

Each venture folder is self-contained and follows the same layout:

```
decisions/   what business, why this one, what was rejected
plan/        business plan, market, pricing, go-to-market, operations, brand
model/       runnable operating model with tests
product/     working product, with tests
templates/   contracts and engagement documents
site/        landing page
```

Every figure in both plans is either cited to a published source or marked as an estimate.
Neither plan required outside capital. In both, the parts that need a human signature —
entity formation, trademark clearance, counsel review — are left as costed checklists rather
than claimed as done.
